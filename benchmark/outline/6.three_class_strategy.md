# 三类无主动攒卡策略讨论稿 v1

2026-11-17 的当前组合见 [自适应调度策略讨论稿 v3（五个启发式策略）](five_strategy_design.md)。本稿保留 2026-11-13 三个基础策略的规则与证明，后续从 v3 接续。

记录日期为 2026-11-13。本稿固定当前讨论的一、二、三类及其分析条件，作为后续继续讨论和实现的接续依据。

当前状态为策略设计稿。现有 benchmark/repo/strategy.py 仍包含早期 LoadAwareStrategy 和 ParallelReserveStrategy 的等待逻辑，本稿中的三类组合尚未实现。

**本版采用时段起点分卡与任务换序，排除主动攒卡。** 第三类的当前版本是“起点部分 P 多卡，后续 P 和 S 全部单卡”，后续讨论应以这一版本接续。

本稿所说的“不慢”以文中列出的模型条件为前提。第二、三类的均值模型结论与真实耗时波动下的实验结论分别记录。

所有任务在单时段起点一次就绪，初始 K 张卡均可用。任务独占分配到的卡，运行期间卡数固定，完成并释放后再调度。本稿分析单时段完整队列，跨时段残留任务需要另行分析。

主要优化指标为本时段清队时间 C，即最后一个任务完成时刻减去时段起点。基线为同一初始任务集、同一原始顺序、同一卡数下的 FIFO 全单卡调度，有卡立即补位。

任务标签、任务内容与图结构作为给定输入。调度决策依据初始任务数量、类型、顺序、当前空卡和可配置卡数。代表耗时用于理论分析，运行时策略不使用单条任务实际耗时预测或逐队列仿真。

| 符号 | 含义 |
|---|---|
| P | parallel，高负载且分卡收益较高 |
| D | debate，负载较低且分卡收益较小 |
| I | iterative，串行任务，始终单卡 |
| S | I 和 D 的合称 |
| K | 本次实际启用的卡数 |
| p、s | 时段起点的 P 数量和 S 数量 |
| n0 | 初始总任务数，n0 = p + s |
| n | 某次决策时尚未启动的任务数，包含队头，排除运行中任务 |
| F | 当前空卡数 |
| C_P、C_D | P、D 的有效分卡上限，分别取配置上限与 K 的较小值 |
| w | 第二、三类在起点分给选中 P 的卡数，为预先配置的整数 |
| q、r | p = qK + r，其中 q = floor(p/K)，r = p mod K |
| T1、Tw | 均值模型中一个 P 单卡和 w 卡的代表持卡时长 |
| τ | S 在所允许分卡配置下的代表持卡时长上界 |

K 由启用设备决定。C_P、C_D 由 config.py 的 K_MAX_TABLE 输入。w 也应由 config.py 作为入参提供，要求 2 ≤ w ≤ C_P，本文示例使用 2。w 的具体配置字段名留待实现时确定。既有 K_WAIT_TABLE 记录的是早期主动等待目标。

第一类的 P 可以分到 C_P，第二、三类选中的 P 固定分 w 张。w 与 k_max 的作用不同。调整 w 后，需要使用对应的 Tw 重新核验模型条件。

均值模型将每个 P 的单卡持卡时长固定为 T1、w 卡持卡时长固定为 Tw，S 在允许配置下的代表持卡时长均不超过 τ。第三类使用 0 < Tw < T1。理论上将起点的一轮分配视为同时启动，实际调度与持卡开销在实验中另行计入。

**分类只在时段起点进行一次，按第一类、第二类、第三类、回退的顺序匹配。** 后续排队数下降时继续执行已经确定的类别，避免把中途缩短的队列当成新的第一类。

空队列直接结束。没有有效的多卡参数时，第二、三类不适用。运行期间 F = 0 时正常等待资源释放。主动攒卡指 F > 0、待执行任务能够单卡启动时，仍将卡空置以凑更大的分卡数，本版排除这种行为。

| 类别 | 初始数量条件 | 顺序 | 分卡安排 |
|---|---|---|---|
| 第一类 | 1 ≤ n0 ≤ K − 1 | 完整原顺序 | 起点先保每个任务一张，富余优先给 P，D 使用相应富余，I 一张 |
| 第二类 | 第一类未匹配，p ≥ 1，wp ≤ K，wp + s ≤ 2K | 稳定提取所有 P 到前面 | 所有 P 在起点各 w 卡，S 按下文规则补位 |
| 第三类 | 前两类未匹配，q ≥ 1，1 ≤ r < K，wr ≤ K，wr + s ≤ 2K | 稳定提取所有 P 到前面 | 起点前 r 个 P 各 w 卡，其余 qK 个 P 和全部 S 单卡补位 |
| 回退 | 三类均未匹配 | 完整原顺序 | 全单卡，有卡立即补位 |

第二、三类稳定提取 P 时，P 之间保留原相对顺序，I/D 之间保留原有的混合相对顺序。在这两类中，P 的启动优先于 S，所有 P 已启动后，有空卡即可启动 S。

当前分类允许存在未覆盖的队列。p = K 或其他 r = 0 的队列不进入第三类，第一类外的 p = 0 队列进入回退。以后扩展准入范围时，应保留本稿作为已有版本。

**第一类保持原顺序，所有任务都在起点获得分配。** 每个任务至少留一张卡，额外卡优先用于 P 的任务内并行，D 使用满足后续预算后的富余卡，I 始终一张。

为固定 FIFO 分配细节，每次根据剩余队列和当前 F 决定队头，完成本次分配后重新计算 n、F 和后续任务预算。初始 n = n0，由 n0 ≤ K − 1 得到 F = K ≥ n0 + 1。逐次分配保持 F ≥ n，每次分配都保留后面每个任务的一卡启动机会。

I 分配一张。P 的分配为

\[
k_P=\min(C_P,\ F-(n-1)).
\]

最后一个 P 也使用这个公式，立即分配 min(C_P, F)。

D 先计算其后续任务的预算

\[
B_{\mathrm{tail}}
=C_P\,p_{\mathrm{later}}+d_{\mathrm{later}}+i_{\mathrm{later}}.
\]

其分配为

\[
k_D=\min(C_D,\ \max(1,F-B_{\mathrm{tail}})).
\]

后续每个 P 在 D 的预算中按 C_P 计入，后续 D/I 按一张计入。预算超出现有空卡时，D 单卡启动。预算用于约束当前 D 的分卡数量，后续 P 仍按当时实际富余卡分配，上限是 C_P。

这组规则维持 F ≥ n 的不变量，因此所有任务都能在起点这一轮分配中启动。即使 P 只分到一张，也直接启动。

第一类的保证依赖两个前提。所有任务与全单卡基线同时启动，且分卡不会增加该任务自身的持卡时长。于是

\[
C_{\mathrm{第一类}}
=\max_j T_j(k_j)
\le \max_j T_j(1)
=C_{\mathrm{基线}}.
\]

这个结论允许各条 P 的耗时不同。额外卡来自基线初始空着的 K − n0 张卡，不挤占其他任务的启动机会。若最终拖尾任务被有效加速，清队可以提前；若仍由未缩短的任务决定终点，则持平。

**第二类将所有 P 提前，并在起点为每个 P 固定分配 w 张卡。** wp ≤ K 保证全部 P 都可以立即启动，剩余 K − wp 张卡立即用于队头 S。

后续继续按 S 的原混合顺序补位。有空卡时 I 分一张，D 保留此前讨论的真富余分卡规则。令 u 为尚未启动的 S 数量，包含当前队头 D，则在 F ≥ 1 时

\[
k_D=
\begin{cases}
1,&F<u,\\
\min(C_D,F-(u-1)),&F\ge u.
\end{cases}
\]

D 获得额外卡时，仍为其他待启动 S 各保留一张。每次启动后重新计算 F、u，继续分配到没有空卡或没有待执行任务。各任务启动后固定卡数。

第二类允许部分 S 排队。其理论保证需要数量条件和耗时条件共同成立。设

\[
B=\max(2\tau,T_w+\tau),
\qquad
2\tau\le T_1,\quad T_w+\tau\le T_1.
\]

令 L2 = K − wp，在起点至少启动 min(L2, s) 个 S。到 max(τ, Tw) 时，所有 P 和最初这批 S 都已完成。由 s ≤ K + L2 可知，未完成的 S 至多 K 个。

若此时仍有 S 排队，运行中的 S 均占一张卡。因为 D 真富余多卡一旦出现，剩余 S 就能在同一轮全部启动。所以这至多 K 个未完成 S 都能最迟在该时刻启动，再经至多 τ 完成。

\[
C_{\mathrm{第二类}}\le B\le T_1.
\]

任意原顺序全单卡都至少需要完成一个单卡 P，因此

\[
C_{\mathrm{基线}}\ge T_1,
\qquad
C_{\mathrm{第二类}}\le C_{\mathrm{基线}}.
\]

B < T1 时可保证模型内严格加速。分析 D 富余分卡时，需要其多卡耗时也被 τ 覆盖，或满足分卡不增加自身耗时。

第二类还允许用一批固定样本的最长单卡 P 时间和最长多卡 P 时间代替 T1、Tw。只要 max(2τ, Tw + τ) ≤ T1，该上界仍成立，并不要求 P 同时结束。实际短任务耗时上界仍需要独立核验。

**第三类采用起点部分 P 多卡，后续全部单卡。** 这是本版最新确定的第三类形式。

执行过程固定如下。

1. 将全部 P 稳定提前，S 保持原混合顺序。
2. 起点前 r 个 P 各分 w 张，立即启动。
3. 除初始 r 个多卡 P 外的 qK 个 P 全部固定单卡，起点先使用剩余 K − wr 张卡启动其中一部分。
4. 每释放几张卡，就立即启动几个尚未启动的单卡 P。
5. 所有 P 已启动后，用现有空卡启动 S，S 全部单卡，直到清队。

S 的启动不以 P 全部完成为前提。第三类按本次“后面单卡”的约定执行，其 S 阶段统一一张卡。

选择 r 个 P 在起点分卡，使剩余 P 数量恰好为 qK。分卡数量由 p、K 的余数决定，选中的任务为稳定排序后的前 r 个 P，运行时无需按样本耗时挑选。

第三类在均值模型下的证明保留以下两组卡。令 L3 = K − wr。

| 卡组 | 卡数 | 单卡 P 的启动时刻 | 最后一批 P 完成 |
|---|---|---|---|
| 第一组 | L3 | 0, T1, …, (q − 1)T1 | qT1 |
| 第二组 | wr | Tw, T1 + Tw, …, (q − 1)T1 + Tw | qT1 + Tw |

第二组先执行初始的 r 个多卡 P，Tw 时释放后才转为单卡 P。由于 0 < Tw < T1，两组事件交错，每轮启动 L3 + wr = K 个单卡 P，qK 个单卡 P 恰好填满两组各 q 轮。

所有 P 最迟在 (q − 1)T1 + Tw 时已经启动，早于 qT1。qT1 前全部卡持续运行任务。此后 S 在 qT1 获得 L3 张卡，在 qT1 + Tw 再获得 wr 张卡。L3 = 0 时，S 从后一个时刻获得全部卡。

由准入条件

\[
s\le2K-wr=K+L_3.
\]

qT1 时先启动 min(L3, s) 个 S。到

\[
A=qT_1+\max(\tau,T_w)
\]

时，全部 P 与最初这批 S 都已结束，未完成 S 至多 max(0, s − L3) ≤ K 个。它们全部单卡，因此最迟在 A 都可以已启动，再过至多 τ 即完成。

\[
C_{\mathrm{第三类}}
\le qT_1+\max(2\tau,T_w+\tau)
=qT_1+B.
\]

原顺序全单卡有 qK + r 个 P，r > 0，至少一张卡必须执行 q + 1 个 P。这给出与原始混排无关的下界

\[
C_{\mathrm{基线}}\ge(q+1)T_1.
\]

结合耗时条件得到

\[
\boxed{
C_{\mathrm{第三类}}
\le qT_1+B
\le(q+1)T_1
\le C_{\mathrm{基线}}
}.
\]

B < T1 时保证模型内严格加速。这一形式通过起点的 r 个多卡 P 改善尾部，同时让剩余 qK 个 P 保持单卡补位。保证的绝对时间差至少为 T1 − B，随 q 增大，该保证对应的相对加速幅度会下降。

第二、三类的时间条件相同，可以写成

\[
T_1\ge2\tau,\qquad T_1-T_w\ge\tau.
\]

分卡省出的时间使每张释放的卡还能执行一个 S，并赶在原单卡 P 的时间窗口结束前完成。另一组从窗口起点可用的卡，至少有时间执行两个 S。第三类对应的数量容量正好为

\[
2(K-wr)+wr=2K-wr.
\]

该解释依赖前面已证明的资源释放过程。统一按 τ 估计是保守分析，D 较多且耗时低于 τ 时，实际排程可能有更大余量。

**资源时间恒等式用于统一分析三类的代价与收益。** 在固定 K 张独占卡、同一统计窗口中，令 W 为任务分配卡数乘以实际持卡时长的总和，H 为从起点到清队的累计空卡时间，则

\[
W+H=KC.
\]

占卡按调度器分配统计，持卡时长从取得卡到释放卡计算，包含持卡期间启动与收尾。常驻引擎的显存占用与 GPU 实际计算利用率不替代这个口径。将 execute 测量用于代表耗时建模时，额外开销需在实测评价中统一处理。

同一卡数下，两种策略满足

\[
C_{\mathrm{新}}-C_{\mathrm{基线}}
=\frac{(W_{\mathrm{新}}-W_{\mathrm{基线}})
-(H_{\mathrm{基线}}-H_{\mathrm{新}})}K.
\]

第一类用初始富余卡承接新增占卡，并保留所有任务的起点启动机会。第二、三类先由排程上界证明任务能及时完成，恒等式相应给出

\[
H_{\mathrm{基线}}-H_{\mathrm{新}}
=(W_{\mathrm{新}}-W_{\mathrm{基线}})
+K(C_{\mathrm{基线}}-C_{\mathrm{新}})
\ge W_{\mathrm{新}}-W_{\mathrm{基线}}.
\]

第三类只有初始 r 个 P 改变卡数，因此

\[
\Delta W=r(wT_w-T_1).
\]

第二类若 D 也使用真富余多卡，新增占卡还需计入这些 D 的变化。不能统一只用 P 的变化代表全部 W 的变化。

**主动攒卡在本版中被排除，是当前研究方法与信息条件下的范围选择。** 当前同类 P 同耗时模型使卡同步释放，无法充分刻画逐张释放造成的主动等待成本，当前讨论尚未建立适用的异步等待模型。

第一类的结构保证允许任务耗时不同。第二类可以在相应最大耗时与短任务上界关系下推广到不同 P。第三类的两组整齐时间线依赖 P 的固定代表耗时，实际差异会改变每张卡上的任务组合。真实数据波动下的加速、持平和退化范围通过后续实验评价。

无主动攒卡本身不能独立保证不慢。换序与额外分卡的效果仍由各类准入结构和耗时分析支撑。

后续接续本稿时，保留以下几项约定。

- 第三类使用起点前 r 个 P 多卡，其余 P 和 S 单卡补位。
- 第二类保留 D 使用真富余卡，第三类所有后续 S 单卡。
- 各类仅按完整初始队列匹配一次，原始顺序可以任意混排。
- k_max 和 w 都是配置输入，示例中的卡数与代表耗时均可调整。
- 均值模型证明不慢与真实运行平均清队时间不慢是不同结论。
- 本稿作为策略设计依据，后续实现另行接入现有调度器。
