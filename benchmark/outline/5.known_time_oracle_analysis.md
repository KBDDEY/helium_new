# 已知执行时间下的分卡参考解

日期：2026-11-12。以下是独立确定性调度模型计算，没有运行 Helium、vLLM 或项目测试，也没有修改运行配置。

## 1. 目的与比较口径

先比较三个量，再从参考解提炼未知耗时启发式：

1. 原始 FIFO 全单卡清队时间。
2. 允许换序的最优全单卡清队时间。
3. 允许换序、允许选择分卡模式的最优清队时间。

第1到第2项是换序收益，第2到第3项才是分卡相对最优单卡的额外收益。
参考解允许任意任务顺序，是一个能力上界；提炼成启发式时，必须恢复实际可观测信息和顺序约束。

## 3. 为什么P卡数要随其他任务改变

纯8P的末2P各三卡：尾部为24.559秒，整队74.906秒。

加入8I后，如果仍将末2P各分三卡，6张卡都被P占据，I需要在P结束后运行两轮，整队为104.906秒，反而慢于最优全单卡100.694秒。

末2P各双卡则留下2张卡处理I，整队96.403秒。由此可见，单个P最快的模式未必让整队最快；要保留后续任务的启动机会。

## 4. 用户前8条P固定曲线的可行分卡解

这里把每条已测曲线当作准确已知的固定时长，并允许P内部重排。它是已知时间参考安排，不是现有未知时间策略，也不证明真实重复运行会得到相同数字。

原始样本顺序全单卡FIFO为96.670秒。
最优全单卡换序为88.750秒：

- P3+P2：42.84+45.91=88.75秒；
- P5+P1：43.50+45.13=88.63秒；
- P0、P4、P6、P7各占一张卡。

最优性理由：8任务分6卡，至少需要两个双任务组合或一个三任务组合。最短三条之和已超过131秒；两个组合的最小最大值为88.75秒。另有对全部单卡分配的对称剪枝枚举核验。

以下混合安排可行，清队75.820秒，比最优全单卡再减少12.930秒（14.57%）。该分卡安排尚未证明全局最优。

## 5. 可提炼的候选规律及限制

- 保留全单卡作为有效答案，不为了分卡而分卡。
- 真正资源富余时，卡数可以超过等待目标2卡，使用已测更快模式。
- 后续任务多时，P过度占卡可能形成新的短任务尾部，应保留启动容量。
- 加速对象不必是最长任务；提前释放资源后能推动哪些后续任务，同样重要。
- 一条最优轨迹不是唯一规律，应对不同队列查找重复出现的结构。
- 若参考解的选择依赖同类型P的精确长短，仅有P/I/D标签和数量未必能复现；后续必须区分哪些规律可由允许的信息实现。
- 不能将上述少量实例直接写成查表策略。需要在未参与规律提炼的队列上比较原FIFO、最佳单卡、参考分卡和未知时间启发式，分清收益来源与信息差距。

当前只是参考解分析，正式保留的第一类、第二类策略未改。
